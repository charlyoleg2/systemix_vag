Systemix\_vag
=============


Presentation
------------

*systemix\_vag* is the top-repo of the *Systemix* ecosystem. It just points to other repositories.

Using [vag\_tools](https://www.npmjs.com/package/vag_tools), it clones the following repositories:

- msysXyz
- systemix\_vag


Getting started
---------------

```bash
git clone https://github.com/MYNAME/systemix_vag
cd systemix_vag
npm i
npm run
npm run vag-clone
npm run vag-pull
ls -la repos
npx vag --help
```
